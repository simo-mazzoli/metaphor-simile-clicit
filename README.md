# Metaphor / Simile — CLiC-it

Research code and data for experiments comparing metaphor and simile processing, including model likelihoods and derived plots.

## Structure

- `compute_likelihoods.py` — likelihood computation.
- `data/` — research data.
- `plots/` — generated visualizations.
- `model_config.txt` — model configuration.
- `stimuli_with_ll_and_cloze_updated (2).csv` — stimulus/likelihood data.

## Reproducibility

Before interpreting results, document the model/version, generation parameters and preprocessing steps used to produce derived files.
